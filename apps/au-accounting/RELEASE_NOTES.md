# v0.1.0

Unreleased. First version: one `au-accounting` command with a subcommand for each
of the 7 Rust engines (`benchmarks`, `div7a`, `exchequer`, `payday-super`,
`solomons`, `tax` and `wip`), linking the engine crates from this repository.
Install with `cargo install --locked --git https://github.com/ryanduguid/australian-accounting au-accounting`;
see [README.md](README.md).
