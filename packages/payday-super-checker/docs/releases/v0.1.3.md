# v0.1.3 - experimental prerelease

Release classification: **experimental prerelease**

The checker remains an experimental review aid. Its output is not a compliance determination,
an ATO assessment or professional advice. A qualified human must
reconcile the source records and approve any payment, disclosure or lodgment.

## Changes since v0.1.2

- Ryan Duguid moved the maintained source to
  `australian-accounting/packages/payday-super-checker`.
- The monorepo workflow builds the wheel and source distribution in the same locked release job,
  records checksums and attestations, then publishes the
  checked files to PyPI. This check is not a cross-platform byte-identity claim.

The calculation rules and known review boundaries match v0.1.2.
