# Domain documentation

This is a single-context repository. Read [`CONTEXT.md`](../../CONTEXT.md)
before changing domain behaviour, public terminology, citations, refusals or
accounting controls. Use its terms consistently in code, tests, issues and
documentation.

Record a durable architectural decision in `docs/adr/` only when it changes a
long-lived design or control boundary. If a proposed change conflicts with an
existing ADR, surface the conflict for a maintainer rather than selecting a
side silently.
