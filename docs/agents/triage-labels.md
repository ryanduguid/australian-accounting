# Triage labels

Use these canonical roles when triaging GitHub Issues. They describe workflow
state; retain classifier labels such as `bug`, `enhancement`, `documentation`
and `question` where useful.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| Needs triage | `needs-triage` | The report has not yet been assessed. |
| Needs information | `needs-info` | Waiting on the reporter for required information. |
| Ready for agent | `ready-for-agent` | The scope, acceptance criteria and boundaries are sufficient for delegated implementation. |
| Ready for human | `ready-for-human` | The work needs a maintainer's decision or action. |
| Will not fix | `wontfix` | The repository will not take this work forward. |
